# Taku Official CocoaPods Specs

The official private CocoaPods Spec repository for Taku (AnyThink) iOS SDK and mediation adapters.

## Usage

Add this spec repository source at the top of your `Podfile`:

```ruby
source 'https://github.com/TakuMediation-packages/Taku_Specs.git'
source 'https://cdn.cocoapods.org/'
```
